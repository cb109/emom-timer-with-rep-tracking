# EMOM Timer with Rep Tracking

A small, single-page EMOM (every minute on the minute) workout timer that tracks the actual reps you did in every interval.

**Open the app: [https://cb109.github.io/emom-timer-with-rep-tracking/](https://cb109.github.io/emom-timer-with-rep-tracking/)**

## Features

- Multi-exercise workouts, each exercise with its own interval time and target reps
- Configurable number of rounds; the full exercise list repeats once per round
- Per-interval rep tracking with +/− buttons, grouped by round
- Save multiple workouts for reuse, with exercise name autocomplete
- Installable as a PWA, works offline, keeps the screen awake while running
- Light and dark theme

All data is stored locally on your device (localStorage); nothing is sent to a server.
